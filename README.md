# darkerlogic-scripts

Quality of life userscripts for everyday browsing, run with [Tampermonkey](https://www.tampermonkey.net/).

Each script targets a specific site, does one small thing, and never collects or sends personal data.

## Installing a script

1. Install the Tampermonkey extension for your browser.
2. Click the script's **Install** link in the table below.
3. Tampermonkey opens an install page showing the script's code and permissions. Review it, then click **Install**.

Scripts update automatically: Tampermonkey periodically checks this repo and installs newer versions.
To check right away, open the Tampermonkey dashboard and choose **Check for userscript updates**.
